Bem-vindo!

Para classificar resíduos com a IA da Anthropic, você precisa de uma chave de API. É grátis criar:

  1. Crie uma conta em console.anthropic.com
  2. Vá em Settings → API Keys e clique em Create Key
  3. Copie a chave (começa com sk-ant-) e cole aqui ao lado

A chave fica salva só no seu navegador.
